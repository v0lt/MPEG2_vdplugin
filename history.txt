MPEG-2 plugin history

4.6.1.37 - 2026-09-13
----------------------
Improved Unicode support.
Fixed setting of color space matrix coefficients if it is not specified in the video stream.
If a MPEG-2 4:2:0 video stream is defined as interlaced, the plugin will output in interlaced format by default.
The minimum supported version is VirtualDub 1.10.1 or later.
